# MO54 Calls Privileged Recorder

Этот модуль предназначен для Redmi Note 8 Pro / Android 10 / MIUI 12, где обычный APK не получает звук обеих сторон звонка.

Что делает модуль:

- устанавливает release APK `ru.mo54.calls` как `/system/priv-app/MO54Calls/MO54Calls.apk`;
- добавляет `privapp-permissions-ru.mo54.calls.xml`;
- добавляет `default-permissions-ru.mo54.calls.xml` для runtime-разрешений;
- позволяет приложению получить `CAPTURE_AUDIO_OUTPUT` / `CAPTURE_VOICE_COMMUNICATION_OUTPUT`;
- после этого MO54 автоматически выбирает `VOICE_CALL` и пишет звонки без ручного нажатия «Запись» и без «Поделиться».

Важно:

- модуль требует Magisk/root;
- текущий тестовый телефон сейчас `locked`, `green`, без `su`;
- разблокировка загрузчика обычно стирает пользовательские данные;
- перед разблокировкой/root нужна резервная копия и отдельное подтверждение владельца устройства.

Сборка zip:

```powershell
./build-module.ps1
```

После установки модуля через Magisk и перезагрузки:

1. открыть MO54 Calls;
2. проверить на вкладке «Диагностика»: `Privileged call-audio: да`;
3. если рядом остался debug-пакет `ru.mo54.calls.debug`, удалить или отключить его, чтобы не было двух PHONE_STATE-приёмников;
4. выполнить 3 входящих и 3 исходящих теста подряд;
5. убедиться, что записи создаются автоматически и обе стороны разборчивы.
