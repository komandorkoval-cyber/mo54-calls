## Решение

- [ ] GO: обе стороны слышны в 3/3 входящих и 3/3 исходящих тестах.
- [x] NO-GO для обычного APK MediaRecorder: публичные источники `VOICE_RECOGNITION`, `MIC` и `VOICE_COMMUNICATION` создают файлы, но в них тишина во время SIM-звонка.
- [x] SOFT-GO для не-root обхода: Google Phone пишет обе стороны через системный Telecom (`VOICE_CALL`/`inputSource 4`) после ручного нажатия «Запись», затем запись можно вручную передать в MO54 через «Поделиться».
- Ограничения: сценарий пока не автоматический — оператор должен нажать «Запись» в Google Phone и после завершения нажать «Поделиться» → «Импортировать в MO54 Calls». Запись в Google Phone субъективно очень тихая, но импортированный WAV содержит ненулевой сигнал.
- Следующий шаг: повторить Google Phone + share-import для 3 входящих и 3 исходящих подряд; затем проверить заблокированный экран, перезагрузку, отсутствие сети, классификацию work/not_work_related и синхронизацию. Для полностью автоматического v1 без ручного share нужен root/system module либо другая прошивка/устройство с доступной системной записью.
