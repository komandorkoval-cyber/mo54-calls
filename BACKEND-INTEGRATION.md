# Подключение существующего backend MO54

Репозиторий backend не находится в этой рабочей папке. После его предоставления
реализация должна следовать `openapi/call-companion.yaml` без создания нового
самостоятельного сервиса.

Обязательные ограничения persistence:

- unique `(device_id, local_call_id)` для звонка;
- unique `(call_id, audio_sha256)` для аудио;
- unique `call_id` для follow-up задачи v1;
- повторный metadata-запрос не заменяет непустой итог пустыми значениями;
- файл становится подтверждённым только после серверной проверки SHA-256;
- `PATCH outcome` обновляет существующую follow-up задачу вместо создания дубля.

Ошибки `408`, `429`, `5xx`, `temporary_storage_error` помечаются retryable.
Ошибки авторизации, валидации, размера, MIME и checksum требуют действия
пользователя. В access-логах запрещены bearer token, полные номера, итог и аудио.

Минимальная проверка интеграции: прогнать Android `ApiContractTest` против
staging, затем сценарии повторной отправки metadata/audio/outcome с теми же
idempotency keys.
