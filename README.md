# MO54 Calls CRM

Отдельная CRM для управления телефонными продажами. Боевой путь пилота —
**мобильный контур Novofon**, а не Android SIP-клиент:

```text
Входящий: клиент → номер Novofon → Redmi по обычной мобильной связи
Исходящий: CRM в браузере Redmi → Novofon callback → Redmi → клиент
События: Novofon → CRM → карточка клиента / звонка / задача
```

Существующее приложение `/opt/mo54` не является частью проекта и не должно
изменяться при развертывании. CRM публикуется отдельным HTTPS-именем
`calls.мягкиеокна54.рф`; её Docker API продолжает слушать только loopback.

## Что входит в v1

- Контакты, звонки, сделки, задачи и аудит ручных изменений.
- Идемпотентный прием событий Novofon по `call_session_id`, включая дубли и
  изменение порядка событий.
- Статусы завершения звонка, ожидания записи, ожидания транскрипта и готовности.
- Callback-исходящие из CRM: менеджер сначала отвечает на обычный мобильный
  вызов Novofon, затем система соединяет его с клиентом.
- Защищенный просмотр записи в Novofon: CRM хранит метаданные, а не делает
  аудио публичным.
- Автозадача обратного контакта для пропущенного входящего.
- Периодическая сверка с Data API Novofon для восстановления пропущенных
  уведомлений.
- Роли `admin`/`manager`, cookie-сессия, защита от подбора пароля и отдельный
  HTTPS ingress без изменений MO54.

В пилоте без подключенной речевой аналитики Novofon CRM **не** запускает
транскрибацию, GigaChat или ИИ-рекомендации. Интерфейс явно показывает
«ожидается»/«недоступно», а не подменяет данные вымышленным анализом.

Asterisk, WireGuard и прежний конвейер сохраняются как диагностический/резервный
контур, но не являются критическими для боевой работы на Redmi.

## Локальная проверка

```powershell
cd asterisk-crm
Copy-Item .env.example .env
# Заменить все changeme/replace_with. Novofon-токены пока не добавляйте в .env:
# для них есть отдельные закрытые .api.secrets.env и .worker.secrets.env.
docker compose config --quiet
docker compose build
docker compose up -d postgres migrate api
```

CRM доступна на loopback: `http://127.0.0.1:8080`. Для боевого доступа создается
новый, независимый nginx virtual host для `calls.мягкиеокна54.рф`; шаблоны и
безопасный запуск находятся в `asterisk-crm/ops/nginx/` и
`asterisk-crm/ops/prepare-calls-ingress.sh`. Маршруты приложения MO54 при этом
не меняются.

Перед первым входом стартовый пароль администратора обязательно меняется в
самом интерфейсе. CRM использует защищённую HttpOnly-cookie-сессию, а не JWT,
и не сохраняет пароль или токен в браузере.
