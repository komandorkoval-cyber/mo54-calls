# MO54 Calls — ежедневная работа

## Перед началом дня

1. Откройте `https://calls.мягкиеокна54.рф` на Redmi или рабочем компьютере.
2. Войдите под своей учётной записью CRM.
3. Откройте «Задачи» и обработайте просроченные/сегодняшние действия.
4. Убедитесь, что телефон Redmi доступен по мобильной связи. SIP-клиенты для этого процесса не нужны.

## Входящий звонок

1. Клиент звонит на городской номер Novofon.
2. Вызов поступает на Redmi как обычный телефонный звонок.
3. После завершения откройте в CRM «Звонки» и найдите новую карточку. Событие обычно появляется быстро; запись провайдера может появиться отдельно.
4. Проверьте контакт, назначьте следующий шаг, создайте/свяжите сделку при необходимости.
5. Если звонок пропущен, CRM должна создать задачу «Перезвонить по пропущенному звонку». Закройте её только после реального действия.

## Исходящий звонок

1. Найдите или создайте контакт в CRM.
2. Откройте карточку контакта и нажмите «Позвонить».
3. Не нажимайте кнопку повторно: дождитесь статуса соединения.
4. Novofon сначала позвонит на Redmi. Ответьте на этот звонок — затем будет соединение с клиентом.
5. После разговора проверьте карточку звонка, запись и следующую задачу.

Не совершайте продажи обычным набором из системной звонилки, если нужен полный след в CRM: такой вызов может не пройти через callback-контур.

## Работа с карточкой звонка

- Исправляйте имя, контакт, сделку и следующий шаг вручную, если автоматическое сопоставление неточно.
- Кнопка «Открыть запись в Novofon» переводит к записи у провайдера. Не передавайте ссылку посторонним.
- Статус «Ожидается запись» не является ошибкой: это означает, что Novofon ещё не сообщил/не выдал запись.
- Статус «Ожидается транскрипт» в пилоте допустим. ИИ-анализ без транскрипта не запускается.

## Если звонок отсутствует в CRM

1. Откройте Novofon → «Отчёты» → «Звонки» и найдите звонок по времени/номеру.
2. Подождите несколько минут: webhook и worker могут обрабатываться асинхронно.
3. Проверьте в CRM «Обработка» ошибки интеграции.
4. Если записи нет более 15 минут, сохраните ID сессии из Novofon и передайте его техническому специалисту. Не публикуйте ключ API или ссылку на запись.

## Если Redmi звонит, но соединения нет

Проверьте в Novofon: номер направлен на сотрудника, мобильный номер сотрудника активен и стоит первым, SIP-номер выключен. При необходимости используйте «Отчёты → Звонки → Детализация» — там указывается причина завершения.

## Перед реальными клиентами

- Уведомляйте о записи разговора по согласованному юридическому тексту.
- Убедитесь в сроке хранения записей Novofon и ограничении доступа.
- Проведите серию тестов, описанную в [PROJECT_STATUS_2026-08-11.md](PROJECT_STATUS_2026-08-11.md).
