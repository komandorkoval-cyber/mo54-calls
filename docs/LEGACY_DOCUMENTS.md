# Статус исторических документов

Исторические документы полезны как журнал решений, но не являются источником текущей архитектуры. Основной набор для работы — `docs/README.md`, `PROJECT_STATUS_2026-08-11.md`, `PRODUCT_SPEC.md`, `NOVOFON_INTEGRATION.md` и `OPERATIONS_GUIDE.md`.

| Источник | Как использовать |
| --- | --- |
| `asterisk-crm-developer-handover.md` | Прочитан при исходном аудите. Использовать только для истории Asterisk/SIP; любые старые учётные данные считать скомпрометированными и не переносить. |
| `asterisk-crm/README.md` | Техническая инструкция исходной реализации. Сверять с актуальными документами, прежде чем выполнять команды. |
| Старые STATUS/GUIDE/Android документы | Контекст по экспериментам Android/SIP; не доказательство готовности боевого пути. |

## Почему произошёл разворот

Тест Redmi подтвердил, что фоновое SIP-соединение через Android/WireGuard неустойчиво: keepalive останавливался даже на UDP 443. Поэтому текущий v1 использует провайдерскую мобильную переадресацию Novofon и callback API. Это архитектурное решение, а не временная «заплатка».
