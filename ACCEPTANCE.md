# Приемка v1

## Автоматические проверки

- Python и JavaScript проходят syntax checks.
- Docker Compose валиден, образы собираются.
- Все SQL migrations повторно применимы к чистой и существующей базе.
- JSON Schema принимает эталонный insight и отклоняет пропуски/лишние поля.
- API health, login, dashboard, calls, tasks и pipeline отвечают с авторизацией.
- Повторный `ingest_asterisk_call` возвращает тот же звонок без дубля.
- Зависшее `running` задание возвращается в `retry`.

## Пилот на телефонии

Провести 10 входящих и 10 исходящих отвеченных звонков. Для каждого проверить:

- один звонок в CRM и правильный контакт;
- две непустые дорожки;
- понятный транскрипт обеих сторон;
- валидный insight без выдуманных фактов;
- возможность исправить контакт, создать сделку и задачу;
- восстановление обработки после рестарта worker.

Пилот не считается пройденным без реального телефона и подтвержденного номера
Новофона. Эти проверки нельзя заменить синтетическим тестом репозитория.
